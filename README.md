# Neuricular — CNS Drug Candidate Screening Pipeline

A cheminformatics tool for rapid CNS drug-likeness assessment combining classical
molecular descriptors, CNS MPO scoring, and machine learning models for
blood-brain barrier permeability and clinical toxicity prediction.

---

## Setup

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Train the ML models

```bash
python ml_model.py
```

The script will attempt to download the BBBP and ClinTox datasets automatically.
If automatic download fails (network restrictions, firewall), see **Manual Dataset Download** below.

On success, two model files are created:
- `bbbp_model.pkl`
- `clintox_model.pkl`

### 3. Launch the app

```bash
streamlit run app.py
```

---

## Manual Dataset Download

If `ml_model.py` cannot reach the dataset URLs, download the files manually and
place them in the same folder as `ml_model.py`:

**BBBP.csv**
```
https://deepchemdata.s3-us-west-1.amazonaws.com/datasets/BBBP.csv
```
Save as: `BBBP.csv`

**clintox.csv** (distributed as .gz — extract after download)
```
https://deepchemdata.s3-us-west-1.amazonaws.com/datasets/clintox.csv.gz
```
Extract and save as: `clintox.csv`

The training script checks for these local files automatically if all remote
URLs are unreachable.
